Экспорт и публикация на GitHub Pages

Чтобы все внесённые вами оценки и задания отобразились на вашем сайте GitHub Pages для студентов:

  1. Нажмите кнопку «Скачать data.json» и сохраните файл в папку вашего репозитория (заменив старый).
  2. (Рекомендуется) Также нажмите «Скачать data.js» и сохраните его в ту же папку (для гарантированной работы без CORS).
  3. Сделайте коммит и отправьте изменения в GitHub: git add data.json data.js
    git commit -m "Update grades"
    git push
  4. Через 1-2 минуты изменения обновятся на вашем сайте GitHub Pages!

Настройки публикации на GitHub

Настройте интеграцию с GitHub REST API, чтобы сайт мог автоматически создавать коммиты при изменении оценок прямо из браузера!

⚪ Интеграция не настроена
🔒 Токен сохраняется только в вашем браузере (localStorage). Он нужен для отправки коммитов от вашего имени.
Создать токен можно на GitHub: Settings → Developer Settings → Personal access tokens → Tokens (classic) с галочкой repo.
